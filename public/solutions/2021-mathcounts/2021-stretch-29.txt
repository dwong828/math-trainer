We can set up a case-by-case analysis using the Stars and Bars method.

Step 1: Set Up the Equation
Let the 5 people be represented by $B_1, B_2, P_3, P_4, P_5$, where $B_1$ and $B_2$ are the two brothers.
Since $B_1 = B_2$, let $k$ be the number of pencils each brother receives.

$B_1 + B_2 + P_3 + P_4 + P_5 = 10$
$2k + P_3 + P_4 + P_5 = 10$

Here, $k$ can be any integer from $0$ to $5$ (since $2k \le 10$). For each choice of $k$, we must distribute the remaining $10 - 2k$ pencils among the other 3 people ($P_3, P_4, P_5$).

Step 2: Use Stars and Bars for Each Case
Distributing $N$ identical items among $3$ people with no restriction (since some people can receive zero pencils) is given by:

$\binom{N + 3 - 1}{3 - 1} = \binom{N + 2}{2}$

Now we sum this over all possible values of $k \in \{0, 1, 2, 3, 4, 5\}$:

Case 1: $k = 0$ (Each brother gets 0 pencils)
Remaining pencils: $10 - 2(0) = 10$
Ways: $\binom{10 + 2}{2} = \binom{12}{2} = 66$

Case 2: $k = 1$ (Each brother gets 1 pencil)
Remaining pencils: $10 - 2(1) = 8$
Ways: $\binom{8 + 2}{2} = \binom{10}{2} = 45$

Case 3: $k = 2$ (Each brother gets 2 pencils)
Remaining pencils: $10 - 2(2) = 6$
Ways: $\binom{6 + 2}{2} = \binom{8}{2} = 28$

Case 4: $k = 3$ (Each brother gets 3 pencils)
Remaining pencils: $10 - 2(3) = 4$
Ways: $\binom{4 + 2}{2} = \binom{6}{2} = 15$

Case 5: $k = 4$ (Each brother gets 4 pencils)
Remaining pencils: $10 - 2(4) = 2$
Ways: $\binom{2 + 2}{2} = \binom{4}{2} = 6$

Case 6: $k = 5$ (Each brother gets 5 pencils)
Remaining pencils: $10 - 2(5) = 0$
Ways: $\binom{0 + 2}{2} = \binom{2}{2} = 1$

Step 3: Sum the Possibilities
$\text{Total Ways} = 66 + 45 + 28 + 15 + 6 + 1 = 161$
